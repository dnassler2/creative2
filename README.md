Random text updating periodically

- +/= or _/- can be used to zoom in or out (this increases/decreases the size of the characters)
- spacebar pauses the animation
- r or R will randomize all text at once.
- j changes the set of characters used
- k undoes the last change to the set of characters used
- [ or ] increases/decreases the speed of the animation
- b or B will decrease/increase the buffer zone at the left and right edges.
- n or N will decrease/increase the buffer zone at the top and bottom edges.
- 0-9 load presets and are initialized with different random charsets and zoom factors
- SHIFT + N will save some of the current state (charset, zoom) as a new preset, under the number N. This will overwrite the previous preset N.
- z or Z will randomize the presets 0-9 either only the charsets (z) or the charsets and the zoom factors (SHIFT + Z)
- a will allow automation of some state (charsets, zoom) to change periodically
